# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [2.28.0] - 2026-09-30

### Added
- FastAPI-based RESTful API server
- User authentication (phone + password, email verification)
- TOTP two-factor authentication
- WebAuthn passkey support
- GitHub/Gitee OAuth login
- Family group management with elderly device binding
- AI health assistant with configurable providers
- Medication plan CRUD and take-record tracking
- Auto-updater with SHA256 verification
