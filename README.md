# 老人用药管理智能助手

一套面向独居老人的智能用药管理系统，包含老人端、服务端、家属看护端（子女端）三个模块，覆盖用药提醒、药品识别、AI 语音问答、服药记录上传、家属沟通、紧急呼叫、库存管理等完整场景。适用于行空板 M10 及通用 Windo
